# 整理会议纪要

根据用户提供的记录输出中文纪要，保留原文明确的时间、负责人和决定。信息不足时标记「待确认」，优先整理现有记录；只有缺失内容影响理解时才询问。

## 工作流程

1. 提取讨论主题与结论，区分已经决定、仍在讨论和单纯建议。只有明确达成的决定进入决策部分。
2. 合并重复观点，为每项待办记录动作、负责人和期限。原文没有的信息写「待确认」；保留「下周五」等相对日期，除非会议日期足以确定具体日期。
3. 对照原始记录，检查遗漏、矛盾和未经确认的推断。存在分歧时保留双方意见及需要谁确认。

## 输出

- **会议概况**：记录中出现的主题、时间和参与人。
- **主要结论与决策**：简述结论，并标记尚未决定的事项。
- **行动项**：使用「事项 / 负责人 / 期限」表格；没有行动项时明确写明。
- **待确认问题**：只列会影响后续推进的信息缺口；没有时省略。

以每项行动都能追溯到原始记录、没有把讨论意见写成决定为完成标准。默认在当前对话交付纪要；外部保存或发送遵循用户的具体请求。
